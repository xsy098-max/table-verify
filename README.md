# TableVerify - 游戏对表工具

一款可视化积木拼装式对表工具，帮助游戏测试人员验证配置表数据是否符合策划设计表。

## 功能特性

- **积木式操作**：通过拖拽/选择积木块组装验证流程，无需编写代码
- **8种积木块**：取值、拆分、查表、批量查表、解析掉落、链式查找、比较、道具映射比较
- **跨表链式查找**：支持多张配置表之间的ID关联查找
- **智能下拉**：自动填充列名、变量名，减少手动输入
- **数据预览**：添加数据源后可预览前10行数据
- **报告导出**：生成Excel格式报告，自动标红差异项
- **任务管理**：保存/加载/复制验证任务

## 安装使用

### 方式一：下载Release（推荐）

从 [Releases](https://github.com/xsy098-max/table-verify/releases) 下载最新版本的zip文件，解压后运行 `table-verify.exe`。

### 方式二：从源码运行

需要 Python 3.12+，安装依赖后直接运行：

```bash
pip install -r requirements.txt
python table_verify.py
```

## 快速开始

1. **添加数据源**：左侧面板点击"+ 添加"，选择设计表CSV和配置表XLSX文件
2. **创建验证组**：右侧面板点击"+ 新建组"
3. **拼装步骤**：选择积木块类型，填写参数
4. **运行验证**：按 F5 或点击"运行"按钮
5. **查看结果**：底部面板显示对比结果，可导出Excel报告

## 支持的文件格式

- CSV（设计表）
- XLSX / XLSM（配置表）

## 技术栈

- Python 3.12
- tkinter（GUI）
- openpyxl（Excel读写）
